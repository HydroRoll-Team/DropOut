# 系统托盘

DropOut 可以在主窗口隐藏后继续驻留系统托盘。在 **设置 → 高级 → 系统托盘** 中启用；修改会立即生效，无需重启启动器。

## 选择生命周期行为

系统托盘总开关控制三个独立偏好：

- **关闭窗口时最小化到托盘**：点击窗口关闭按钮时隐藏 DropOut；确实需要结束启动器时，请使用托盘菜单中的 **退出 DropOut**。
- **启动时最小化到托盘**：由你或桌面会话启动 DropOut 时，直接在后台打开。
- **启动 Minecraft 后最小化**：仅在游戏进程成功启动后隐藏启动器；启动失败时仍保留故障恢复界面。

关闭总开关会移除托盘图标并恢复正常的窗口关闭行为，但不会清除三个已保存的偏好。

## 使用托盘菜单

托盘菜单提供：

- **显示 / 隐藏窗口**；
- **快速启动**：显示最多三个最近游玩且已选择 Minecraft 版本的实例；
- **下载管理**：显示限制在 0–100% 的进度，并可打开下载监视器；
- **退出 DropOut**：明确结束启动器。

快速启动复用主页相同的账户、Java、文件就绪、内存、单游戏限制与错误处理。实例已就绪时会立即启动；未就绪时会显示对应恢复状态，缺失游戏文件则进入经过核对的安装流程，不会启动不完整实例。成功启动后，最近实例顺序会同步更新。

Windows 可双击托盘图标显示或隐藏窗口；macOS 可单击图标；Linux 桌面环境因托盘点击事件支持不一致，请从托盘右键菜单使用同一操作。

## 后台通知

启用托盘后，DropOut 会在以下情况发送桌面通知：

- 当前所有下载任务完成；
- Minecraft 异常退出；
- 存在新的启动器版本。

下载进行中时，托盘图标会显示进度徽标；托盘提示和支持该能力的桌面面板也会显示同一份受限进度。关闭系统托盘总开关即可停止这些后台通知。
