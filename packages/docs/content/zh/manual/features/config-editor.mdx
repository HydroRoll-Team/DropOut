## 概览

DropOut 内置了 Visual Studio Code 同源的 Monaco 编辑器，用于高级启动器配置。编辑器及其 JSON Worker 随应用一同打包，无需从 CDN 加载代码，离线时也能继续提供高亮和校验。

打开**设置**，然后选择**打开 JSON**。工作台会显示当前配置路径、光标位置、校验状态以及是否存在未保存编辑。

## 安全编辑

- 架构感知诊断会在保存前标出字段错误和无效 JSON。
- **格式化 JSON**会格式化整个文档。
- **重置**会恢复到最近一次保存的版本。
- **保存更改**只会写入有效且有变化的 JSON。Windows/Linux 可按 <kbd>Ctrl</kbd>+<kbd>S</kbd>，macOS 可按 <kbd>Command</kbd>+<kbd>S</kbd>。
- 有未保存编辑时关闭工作台，会先要求确认是否放弃更改。

文档未变化或校验失败时，保存按钮保持禁用。保存成功后，主题和显示语言等受支持设置会立即生效。

## 注意事项

配置编辑器会暴露完整的启动器配置。日常调整优先使用普通设置控件。直接编辑 JSON 时，请保留字段名和值类型；状态栏会说明首个阻塞保存的问题。
