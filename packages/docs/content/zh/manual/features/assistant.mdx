# 诊断助手

诊断助手可以把启动输出整理成简短的恢复方案，同时不会在后台静默上传当前会话。它支持本地 Ollama 端点与 OpenAI 兼容的远程端点。

## 配置模型提供方

从启动器侧栏打开**诊断助手**，然后使用**助手设置**：

1. 启用助手。
2. 选择 **Ollama · 本地**或 **OpenAI 兼容 · 远程**。
3. 填写端点和模型名称。远程提供方还需要 API 密钥。
4. 选择**保存并检查提供方**。

只有配置完整且提供方能够响应时，状态才会变为**已就绪**。

## 诊断启动失败

启动失败后，在概览页选择**询问诊断助手**。DropOut 会打开恢复工作台，填入诊断问题，并显示最近会话证据的预览。

发送前：

- 检查证据预览。
- 只有预览内容与问题相关时，才保留**附加到下一次请求**。
- 关闭该选项即可只发送对话，不附加游戏日志。

附加选择按每次请求生效。选择**发送**后，对话文本始终会发送给当前配置的提供方。

## 隐私边界

在会话证据进入预览或模型前，DropOut 会移除常见凭据、用户目录名、邮箱地址与 IP 地址。预览展示的就是可附加证据；原始缓存日志不会绕过界面自动加入请求。

Ollama 请求会发送到你配置的本地端点。OpenAI 兼容请求以及你附加的证据会离开设备并发送到配置的远程端点；提供方自身的保留与隐私条款仍然适用。

## 提供方不可用

如果助手显示**不可用**：

- 使用 Ollama 时，启动服务并确认端点和模型名称。
- 使用远程提供方时，确认端点、模型与 API 密钥。
- 修正后选择**重试**，或再次保存设置。

助手离线时，启动器与普通日志查看功能仍可继续使用。
