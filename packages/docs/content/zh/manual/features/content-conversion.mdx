# 内容转换

内容转换会针对不同的 Minecraft 版本或加载器创建一个新的隔离实例。转换期间源实例只读，DropOut 会先复制再处理，绝不会直接改写源实例。

## 开始转换

打开 **实例**，在实例操作菜单中选择 **转换内容**。在“源环境 → 目标环境”区域：

1. 确认受保护的源实例、Minecraft 版本和加载器。
2. 输入目标 Minecraft 版本。
3. 选择 **原版**、**Fabric** 或 **Forge**；需要时再选择加载器版本。
4. 点击 **扫描兼容性**。

DropOut 会清点已启用和已禁用的模组 JAR、资源包、光影包，以及每个存档中的数据包。启动器只计算本地文件哈希用于识别，不会上传文件内容。

## 阅读转换清单

风险项会优先排列，确保创建副本前能先看到所有待决定内容。

| 状态 | 含义 | 应用行为 |
| --- | --- | --- |
| **保留** | 原文件支持目标环境，或可移植内容仍使用同一 Minecraft 版本。 | 复制后的文件保持原位。 |
| **替换** | Modrinth 提供同一项目的兼容版本。 | DropOut 将兼容文件下载到目标副本，并且只移除副本中的旧文件。 |
| **需审查** | 无法识别文件，或在线查询暂时不可用。 | 将其排除出目标副本，否则转换保持阻塞。 |
| **不兼容** | 未找到同一项目的兼容版本。 | 如有替代项目可先打开核对，再排除不兼容文件；否则保持阻塞。 |

在线匹配使用文件的 SHA-1 标识，并按目标 Minecraft 版本和适用加载器筛选项目版本。查询失败会进入“需审查”，而不会被静默视为兼容。

## 安全应用

只要仍有“需审查”或“不兼容”项目未明确处理，**创建转换副本**就保持禁用。排除项目只会从新副本中移除该内容。兼容替换会先下载到临时文件，下载成功后才原子替换副本内的旧文件。

内容方案成功后，DropOut 会安装所选 Fabric 或 Forge 档案，并更新副本实例元数据。复制完成后的任意步骤失败都会清理未完成的目标实例。源实例的加载器、模组、内容包、存档和配置始终保持不变。

## 回滚

完成报告会列出替换项和排除项，并提供 **撤销转换**。撤销只删除本次操作记录的转换副本，不会触碰源实例。启动器重启后，内存中的一键回滚令牌不再存在，请改用普通的实例导出/删除流程。

如果需要先从其他启动器搬入环境，请阅读[启动器迁移](/docs/manual/features/migration)。其他实例操作请继续查看[实例库](/docs/manual/features/instances)。
