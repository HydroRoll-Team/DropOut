# 实例库

实例库用于管理 DropOut 中所有隔离的 Minecraft 环境。选择某个实例时，它也会成为主页启动指挥中心使用的当前实例，因此实例库与启动状态不会指向不同环境。

## 查找实例

搜索框可匹配实例名称、Minecraft 版本、加载器或备注。可以按以下方式排序：

- **最近游玩**：优先显示常用环境；
- **名称**：便于浏览大型、结构化实例库；
- **创建时间**：优先显示最近创建或导入的环境。

列表视图适合高密度实例库，网格视图让较小的实例库更易区分。DropOut 会在当前设备上记住所选展示方式。

## 查看启动状态

可见实例会被渐进检查，避免大型实例库一次发起数百个运行时探测。就绪标记与主页使用同一个后端检查，并综合已选 Minecraft 版本、本地游戏文件、兼容 Java、账户和内存覆盖。

右侧当前工作区会显示：

- Minecraft 版本、加载器和启动就绪度；
- 本地文件与 Java 可用性；
- 内存与 Java 覆盖；
- 已启用和已禁用的模组数量；
- 备注、创建时间和托管游戏目录。

将 **启动当前实例** 作为主要操作。打开其他实例卡片会同步修改全局当前实例，包括主页。

## 管理与迁移环境

次要命令统一收进实例菜单，可打开游戏目录、编辑元数据和运行时覆盖、复制环境、[转换 Minecraft 版本或加载器](/docs/manual/features/content-conversion)、管理模组、浏览内容、导出 ZIP 或删除实例。当前工作区也会重复最常用快捷操作，同时保留启动状态。

通过 **实例库操作** 可以导入 ZIP、从 Prism/MultiMC 或 PCL/HMCL 迁移实例，或根据磁盘目录修复实例索引。[启动器迁移指南](/docs/manual/features/migration)详细说明核对清单、来源安全、回滚和兼容性报告。

## 安全删除

删除会移除托管的游戏目录，且无法从 DropOut 撤销。如果以后可能需要存档、模组、资源包或配置，请先导出实例。如果目标名称或恢复方案不正确，请取消确认对话框。
