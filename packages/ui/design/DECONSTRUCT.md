# DropOut 界面重设计 · 解构

> 分支 `feat/ui-deconstruct`。粒子方块世界那一版（`feat/ui-redesign-prototype`）原样保留，不在这条分支上。
> 参考：TypeSafe AI 官网（jev）。只借它的语法，不抄它的品牌。

## 0. 一句话

把启动器画成一张还没收拾干净的施工图：网格、轴号、裁切角、尺寸线都露在外面；
超大的字被切开、错位，其中一个字被「丢掉」只剩轮廓；窗口互相压着、微微歪斜；
有些文字表面上是一串 base64，复制下来解码才读得到。

DropOut 这个名字本来就是神经网络里的 dropout：训练时随机丢掉一部分神经元，剩下的更强。
所以「丢掉」是贯穿全局的母题：被丢掉的字、被丢掉的方块、被丢掉的神经元，都只剩一圈虚线。

## 1. 为什么换掉粒子

维护者觉得粒子太花。粒子版的主角是一团会动的东西，界面退到细线和字后面；
这一版反过来：**没有主角，结构本身就是画面**。动的东西只剩两处小部件，都很慢，
而且在减弱动效和测试夹具里完全静止。

## 2. 尺寸规则（照官方启动器）

官方 Minecraft 启动器的界面是**固定尺寸**的：字号、按钮、栏宽都是固定像素，只跟系统显示缩放（125%、150%）走
（参考 Mojang 的 MCL-10940）；窗口随便拉，不锁比例，只有最小尺寸；窗口变大时多出来的地方给画面，
界面本身不变大。具体像素数官方没公开，这里照的是规则。

- 界面全部是固定 CSS 像素：不用 `transform: scale()`，不调 webview 的 `setZoom()`，字号不按窗口宽高算（不用 `cqw`/`vw` 字号）。
  系统缩放由 webview 的 `devicePixelRatio` 处理，不用写代码。
- 窗口最小 905×575（`src-tauri/tauri.conf.json`），不锁比例、不吸附。无边框窗口的拖动、最小化 / 最大化 / 关闭、
  右键菜单在 `src/lib/desktop-window.ts`；`src/components/shell/stage.tsx` 只是一个铺满窗口的根节点。
- 窗口变大，多出来的空间这样用：

  | 部分 | 规则 |
  | ---- | ---- |
  | 施工网格 | 格子固定约 84×89（默认窗口内容区 1006×711 正好 12 × 8 格），铺满窗口，窗口越大格子越多；轴号按格数生成，列号 Z 之后接 AA、AB… |
  | 首页 | 左栏固定 551 宽贴左，右边那叠窗口固定 388 宽贴右，中间是留白；抖色天空铺满宽度，高度固定 355.5 |
  | 实例页 | 列表伸缩，右边详情栏固定 394；网格视图每张卡至少 260，窗口越宽列越多 |
  | 助手页 | 对话区伸缩（气泡最宽 720），右边上下文栏固定 292 |
  | 设置页 | 版心最宽 1006（默认窗口里的宽度），贴左，不跟着变宽 |
  | 章节大数字 | 02 / 03 / 04 的右边缘钉在默认窗口里的位置，窗口窄时往左让，不压右上角的按钮 |

- 放不下的时候在自己那一栏里滚动，不缩小字。最小窗口下首页右栏变窄（最窄约 268），
  两个窗口的错位收小，DAYLIGHT 小部件收起，页面纵向滚动。
- 弹出层（对话框、下拉、菜单）挂在 body 上；对话框「不超过窗口」的约束用 `vh`/`vw`，这不算缩放。
- 状态栏和 F3 的坐标就是窗口坐标；F3 里写窗口尺寸和 devicePixelRatio。

## 3. 解构手法对照

| 手法 | 在界面里的样子 |
| ---- | ---- |
| 暴露结构 | 全局施工网格（默认窗口 12 列 × 8 行，顶上 A–L、左边 1–8 轴号，窗口大了格子更多），四角套准记号 ⊕；首页标题下方一条实时量出来的尺寸线 `W 551` |
| 碎片 / 错位 | 标题除第一行外整体缩进半格；每句标题按固定规则丢掉一个字（只剩描边），并拉一条引线标注 `DROPPED · p=0.50` |
| 叠压 / 倾斜 | 首页右侧 INSTANCE.CFG、READINESS.SYS、两个小部件互相压着，小部件转 −2.2° / 1.6°；一块旋转的虚线框「被丢掉的方块」压在标题后面 |
| 印刷错版 | 当前实例、按钮悬停、输入框聚焦时，身后露出一道偏移的粉色色块 |
| 巨大的章节号 | 实例 02、助手 03、设置 04 的页头后面压一个空心大号数字，被页面切掉一部分 |
| 第二层文本 | 侧边竖排密文、`[B.64]` 块、状态栏中间那串，见第 7 节 |
| 字体冲突 | 挤紧的无衬线大字 + 像素等宽小字 + 等宽说明字，三种声音同时说话 |

## 4. 从 jev 借来的

- 白色标签贴在色场上的导航（当前页反成黑底）。
- 抖色（dither）色场：首页上半截是一块静态的像素云，往下散成纸面。
- 复古系统窗口：黑色标题栏 + 像素字「文件名」（`INSTANCE.CFG`、`SESSION.LOG`…），1px 墨线、硬投影。
- 引导点线 `标签 ……… 数值`、左边一道竖线的文字栏、`∵ x` 分节记号、分段进度条。
- 超大的下划线链接当主操作（`▶▶▶ Launch`）。
- 竖排 base64、`[B.64]` 块、页脚 base64 这类彩蛋。

jev 自己用的 Die Grotesk 和 LisaTerminal 是商业字体，这里换成开源替代（见第 5 节）。

## 5. 配色与字体

| 记号 | 纸面（浅） | 墨面（深） | 用途 |
| ---- | ---- | ---- | ---- |
| `paper` | `#eeece7` | `#171717` | 背景 |
| `sheet` | `#fbfaf7` | `#1f1f1f` | 窗口、卡片 |
| `ink` / `rule` | `#1e1e1e` | `#eceae4` | 文字、1px 墨线 |
| `win` | `#dedede` | `#2c2c2c` | 窗口里的灰色控制区 |
| `signal` | `#f386a1` | 同 | 错版色块、当前项小方块 |
| `go` | `#43b581` | `#4cc48c` | 启动、就绪（DropOut 图标原本的绿） |
| `sky` / `warn` / `fault` | 蓝 / 黄 / 红 | 同 | 天空、警告、错误 |

`go-ink` / `warn-ink` / `fault-ink` 是同色系的深色版，专门给文字用，保证对比度。
圆角全部为 0。shadcn 的 `primary` 映射成墨色，`accent`（菜单高亮）是反白。

字体全部本地打包，不走 CDN（Tauri 的 CSP 也不允许）：

- 大标题：Inter Tight（`type-display`，字距 −0.055em，行距 0.86；中文自动放宽）
- 正文：Inter
- 像素小字：Departure Mono（OFL，文件和授权在 `src/assets/fonts/departure-mono/`）
- 等宽：JetBrains Mono
- 中文回落到系统字体（苹方 / 雅黑 / Noto Sans CJK）

  dither-sky.tsx              抖色天空（静态，按尺寸和主题重画）
  widgets.tsx                 DROPOUT 神经元小部件、DAYLIGHT 游戏时钟

shadcn 基础组件（按钮、对话框、下拉、选择、选项卡、开关…）直接改了样式，
所以向导、编辑器、弹窗这些没单独重写的地方也跟着换了语言。对话框统一成系统窗口，
标题栏默认写 `DIALOG.SYS`，可以用 `chrome` 换。

## 8. 测试

- 功能测试全部通过（可访问性、键盘、各种启动状态、迁移、助手…）。
- 新增「界面不随窗口缩放」：905×575、1024×768、1280×720、1920×1080、2560×1440 五种窗口下，
  首页标题、启动按钮、导航的 computed font-size 和尺寸完全一样，左栏和右栏不重叠，没有横向滚动。
- 助手页图片彩蛋那条：最小窗口里它在页面折线以下，测试先把它滚到中间，再检查完整可见、能复制。
- 截图基线全部重画：只重新生成了 Linux 的（CI 跑在 Ubuntu 上），macOS 的旧基线没动。
  - default-window（1024×768）基本不变，只有字号取整带来的亚像素差异（标题 73.7 → 74 这类）；网格和天空逐像素一致。
  - minimum-window 改回 905×575，从「整张画板缩小」变成 1:1 排版，放不下的部分要滚动才看得到。
- 截图要逐像素一致，所以夹具模式下：时钟固定在一个时刻、DROPOUT 小部件不跳、抖色天空用固定种子。
- 系统缩放：用 `deviceScaleFactor: 1.5` 截图，整个界面按 1.5 倍放大，排版和 1 倍一样。

## 9. 没做 / 下一步

1. Tauri 窗口里的 WebKitGTK 还没实测（抖色天空是 2D canvas，风险比粒子小得多）；拉窗口、最大化也只在浏览器里按尺寸验过。
2. 浏览页（Modrinth）只换了页头和列表行，卡片可以再做得更像「目录卡」。
3. 实例编辑弹窗、导入/转换向导只换了基础组件和颜色，没有逐屏打磨。
4. 设置里可以加一个「施工网格」开关，给觉得线太多的人关掉。
